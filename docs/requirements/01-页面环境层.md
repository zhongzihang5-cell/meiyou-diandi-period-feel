# 记录心智 · 页面环境层需求逻辑

> 所属心智图：**记录心智 → 页面环境层**  
> 覆盖子项：标题 / 副标题、页面背景、暗黑模式  
> 关联实验：方案四底部 Tab 命名 AB（控制组「记录 + 点滴」 / 实验组「日历 + 记录」）  
> 状态：需求初稿（对齐当前 demo / Tweaks「头部氛围感」四方案）  
> 最后更新：2026-08-27

---

## 1. 层定义与边界

### 1.1 本层解决什么

页面环境层负责用户进入「记录时间轴」后的**第一眼环境感**：叫什么、副文案说什么、背景什么气质、深色如何适配。它不负责卡片内容、图表反馈、输入框文案（那些属于其他层）。

### 1.2 本层包含

| 子项 | 说明 |
|------|------|
| 标题、副标题 | 顶栏标题、Hero 大标题、副文案 / 轮播文案 |
| 页面背景 | 浅色默认与可选氛围底色（暖白 / 柔粉等） |
| 暗黑模式 | 深色主题下的背景、标题、副文案、顶栏渐变适配 |

### 1.3 本层不包含（留给后续文档）

- 时间轴骨架（日期节点、亮起方式）
- 用户原始记录 / 标签 / 图表反馈
- 输入占位与空状态（页面状态层）

### 1.4 方案总览

「头部氛围感」拆 **四个方案**，验证不同信息架构与品牌露出强度。  
**方案四额外承载 Tab 命名 AB**（见 §6）。

| 方案 | 一句话 | 标题主词 | 副标题 | Tab 命名 |
|------|--------|----------|--------|----------|
| 方案一 | 左侧大标题 + 副标题，上滑收成顶栏居中小标题 | 点滴 | 有（固定） | 控制组：记录 / 点滴 |
| 方案二 | 看到「今天」时展开；滑走后收成居中小字 | 点滴 | 有（固定） | 控制组：记录 / 点滴 |
| 方案三 | 顶栏居中「点滴」；今天下灰点轮播氛围文案 | 点滴 | 有（今天下轮播） | 控制组：记录 / 点滴 |
| 方案四 | 仅居中标题；无副标题；实验组 Tab | 记录 | 无 | **实验组：日历 / 记录** |

## 2. 通用规则（四方案共用）

### 2.1 生效页面与互斥

- **生效**：点滴 / 记录时间轴主壳（`showRecordShell` 且非搜索全屏、非空预览独占等）。
- **不生效或降级**：
  - 搜索页全屏时，可隐藏常规氛围头。
  - 育儿「喂养」专用顶栏（「全部」筛选）时，不走四套氛围方案。
  - 空记录预览 / Blank 等特殊壳，按各自页面状态层规则，不强制套用本层 Hero。

### 2.2 标题层级语义

| 角色 | 字号建议（对齐美柚规范） | 字重 | 用途 |
|------|--------------------------|------|------|
| Hero 主标题 | 28px | Medium(500) | 方案一 / 二展开态大标题 |
| 顶栏居中标题 | 17px | Medium(500) | 吸顶 / 收起后的主标题 |
| 副文案 | 14px 或 12px | Regular(400) | 「在美柚，记一切」等 |
| 迷你轮播 | 12px～14px | Regular(400) | 方案三右侧 tagline |

主色文字：浅色 `rgba(0,0,0,0.8)`；暗黑 `rgba(255,255,255,0.9)`。  
副文案：浅色 `rgba(0,0,0,0.6)` 或更淡；暗黑 `rgba(255,255,255,0.5～0.6)`。

### 2.3 页面背景（主题）

背景是**横切能力**，可与任一头部方案叠加（Tweaks「主题」）。

| 主题 | 背景色 | 说明 |
|------|--------|------|
| 默认 | `#f2f2f5` | 设计规范浅色页底 |
| 暖白 | `#F6F3F2` | 更暖的氛围底 |
| 柔粉 | `#FAF4F5` | 轻粉色氛围底 |
| 暗黑 | `#323232`（辅底 `#2a2a2a`） | 见 §2.4 |

规则：

1. 主题只改环境色，不改四套方案的交互逻辑。
2. 卡片表面在浅色主题保持白底；暗黑主题改为深灰表面（如 `#3d3d3d`）。
3. 禁止为氛围感叠加厚重投影或多层复杂渐变装饰（规范禁止事项）。

### 2.4 暗黑模式

1. **触发**：用户系统深色或产品内主题切换至「暗黑」（demo 用 Tweaks「暗黑」模拟）。
2. **必须适配**：
   - 页底、顶栏（含方案三迷你条）、Hero 区背景渐变
   - 主/副标题颜色
   - Tab 栏、输入栏对比度
3. **顶栏暗黑渐变建议**：顶部略偏品牌暗紫红过渡到页底，避免死黑一块。
4. **品牌红 `#ff4d88`**：仅保留在核心交互（选中 Tab、关键按钮等），标题不滥用品牌色。
5. **方案差异**：暗黑不改变「收起阈值 / 轮播 / Tab 命名」逻辑，只改变渲染色值。

### 2.5 右侧搜索

方案一 / 二 / 三 / 四：顶栏右侧均保留搜索入口（方案三与默认顶栏一致，不再用迷你条挤掉搜索）。

## 3. 方案一：左侧大标题 + 上滑收缩

### 3.1 目标

进入时间轴时强化「点滴」品牌与口号；上滑后让出内容区，标题收到顶栏居中，信息不丢。

### 3.2 标题 / 副标题逻辑

| 状态 | 表现 |
|------|------|
| 展开（接近列表顶部） | 内容区上方左侧：**大标题「点滴」** + **副标题「在美柚，记一切」** |
| 收起过程 | 随列表上滑，Hero 透明度下降、略上移并缩小；顶栏居中「点滴」渐显 |
| 收起完成 | Hero 不可见；顶栏居中标题「点滴」稳定展示 |

触发建议：

- 以列表 `scrollTop` 映射收起进度（demo 约 0～72px 拉满）。
- 进度阈值中值后（约 >0.45）顶栏标题视为「已显示」；接近拉满时 Hero `aria-hidden`。

### 3.3 背景

跟随当前主题（默认 / 暖白 / 柔粉 / 暗黑）。Hero 区可与顶栏共用同一底色或轻渐变，避免 Hero 与列表「断层」。

### 3.4 暗黑

Hero / 顶栏标题与副文案使用深色主题文字色；副文案对比度不低于辅助文字规范。

### 3.5 Tab 命名

走 **控制组**：第二 Tab「记录」、中间 Tab「点滴」（见 §6）。

### 3.6 验收要点

- [ ] 首次进入可见「点滴」+「在美柚，记一切」
- [ ] 上滑后大标题消失，顶栏居中「点滴」出现，无闪跳
- [ ] 下滑回到顶部可恢复 Hero
- [ ] 暗黑下标题可读

## 4. 方案二：跟随「今天」可见性展开 / 收起

### 4.1 目标

氛围标题与**「今天」日区块是否在视口内**绑定：用户在看今天时强化品牌，划走今天后收成安静顶栏。

### 4.2 标题 / 副标题逻辑

| 状态 | 表现 |
|------|------|
| 「今天」日头在视口内（有足够重叠） | 展示 Hero：**点滴** + **在美柚，记一切**（可位于顶栏下方、列表上方） |
| 「今天」滑出 / 重叠不足 | Hero 收起；顶栏进入 collapsed，居中小标题「点滴」 |
| 无「今天」节点 | 视为收起态 |

触发建议（对齐现实现）：

1. 查找 `.tl-day-section-head.is-today`。
2. 计算与时间轴可视区域的垂直重叠：
   - 重叠 ≥ 阈值（如 48px）→ 进度 0（展开）
   - 重叠 ≤ 0 → 进度 1（收起）
   - 中间线性插值
3. 进入方案二时可先滚到底部，保证默认落在「今天」附近（演示友好）。

### 4.3 背景 / 暗黑

同通用规则；collapsed 顶栏背景与展开 Hero 过渡需平滑（可用同一渐变底）。

### 4.4 Tab 命名

控制组：记录 / 点滴。

### 4.5 与方案一差异（需求层）

| 维度 | 方案一 | 方案二 |
|------|--------|--------|
| 收起驱动 | 列表滚动距离 | 「今天」是否在视口 |
| 用户感知 | 「往上滑就收」 | 「离开今天就收」 |
| 历史日浏览 | 仍可能因 scrollTop 收起 | 明确离开今天才收 |

### 4.6 验收要点

- [ ] 停留在今天：可见大标题 + 副标题
- [ ] 上滑到更早日期：Hero 收起，顶栏「点滴」
- [ ] 回到今天：Hero 恢复
- [ ] 无今天数据时降级为收起，不报错

## 5. 方案三：顶栏居中「点滴」+「今天」下灰点轮播

### 5.1 目标

顶栏与默认一致（居中「点滴」+ 搜索），不占用额外吸顶条；氛围短句落到时间轴 **「今天」日期节点下方**，用**灰色圆点 + 灰色文案**呈现，形态对齐经期感受引导方案二的时间轴打点提示。

### 5.2 标题 / 副标题逻辑

| 元素 | 规则 |
|------|------|
| 顶栏主标题 | 居中 **「点滴」**，布局与默认顶栏相同（左搜索 / 中标题 / 右占位） |
| 吸顶迷你条 | **取消**（不再左右分栏标题+轮播） |
| 氛围文案位置 | 「今天」日头下方，新增一条时间轴节点 |
| 节点视觉 | **灰色圆点**（弱于常规记录节点）+ 右侧灰色文案 |
| 文案内容 | **轮播**，默认池：① 在美柚，记一切 ② 一句话，记下生活点滴 ③ 今天想记点什么？ |
| 切换节奏 | 约每 3.2s 换一句；先淡出再淡入（约 280ms） |
| 滚动 | 文案节点随「今天」区块滚动，不吸顶 |

### 5.3 背景

顶栏、页底跟随当前主题；灰点节点无独立色块背景。

### 5.4 暗黑

顶栏「点滴」用深色主文字；灰点与轮播文案用深色辅助文字（约 `rgba(255,255,255,.45)`）。

### 5.5 Tab 命名

控制组：记录 / 点滴。

### 5.6 验收要点

- [ ] 顶栏居中「点滴」，有搜索，无右侧轮播条
- [ ] 「今天」下方出现灰色圆点 + 氛围文案
- [ ] 文案按间隔轮播且有淡入淡出
- [ ] 形态接近经期感受引导方案二（灰点 + 灰字），但不抢记录节点视觉

## 6. 方案四：居中「记录」+ Tab 命名 AB

### 6.1 目标

弱化「点滴」品牌词在页内的露出，把该屏心智改成 **「记录」**；并通过 **AB 实验**验证底部 Tab 命名：  
**控制组「记录 + 点滴」 vs 实验组「日历 + 记录」**。

> 说明：方案四的「头部氛围」与「Tab AB」绑定投放。实验组用户看到方案四头部 + 实验组 Tab；控制组用户保持方案一/二/三之一的头部逻辑 + 控制组 Tab（具体对照流量分配由实验平台配置，见 §6.4）。

### 6.2 标题 / 副标题逻辑

| 元素 | 规则 |
|------|------|
| 顶栏标题 | 居中 **「记录」**（不是「点滴」） |
| 副标题 | **不展示**（无 Hero 口号、无轮播） |
| 收起动画 | **无**（无方案一/二式进度收起） |
| 搜索 | 保留右侧搜索 |

### 6.3 页面背景 / 暗黑

同通用主题能力；因无副标题，暗黑适配重点在居中「记录」与顶栏对比度。

### 6.4 Tab 命名 AB 实验

#### 6.4.1 实验假设

- **H0（控制组）**：第二 Tab 叫「记录」、中间 Tab 叫「点滴」——用户能区分「日历式经期记录」与「点滴时间轴」。
- **H1（实验组）**：第二 Tab 叫「日历」、中间 Tab 叫「记录」——用户更清楚中间 Tab 是「记事情」的主入口，且与日历职责不混淆。

#### 6.4.2 分组与表现

底部五 Tab 顺序不变：`美柚 / {第二} / {中间} / 回顾 / 我`。

| 分组 | 第二 Tab（原 cal） | 中间 Tab（原 note，中心位） | 页内顶栏标题 |
|------|--------------------|-----------------------------|--------------|
| **控制组** | 记录 | 点滴 | 随方案一/二/三为「点滴」 |
| **实验组（方案四）** | 日历 | 记录 | **记录** |

图标可沿用现有日历 / 麦克风（或记录）图标；**AB 只改文案与页内主标题词，不改信息架构顺序**。

#### 6.4.3 分流与埋点（需求）

| 项 | 要求 |
|----|------|
| 分流单位 | 用户维度（同用户多次进入保持同组） |
| 流量建议 | 初版 50/50；可按量级调整 |
| 曝光 | `tab_label_ab_expose`：group=`control`\|`experiment` |
| 点击 | `tab_click`：tab_id + label_shown + group |
| 核心指标 | 中间 Tab 次日留存、记录发起率、日历 Tab 点击率、记录完成率 |
| 护栏 | 经期相关记录是否下降、搜索使用率是否异常 |

#### 6.4.4 互斥与回滚

1. 同一用户不可同时看到两套 Tab 文案。
2. 实验结束：全量控制组 **或** 全量实验组；若全量实验组，头部默认策略需同步定为「居中记录、无副标题」（或另开迭代）。
3. 回滚：远程开关关闭实验组 → 恢复控制组文案，无需发版改死代码（理想态）。

### 6.5 验收要点

- [ ] 方案四顶栏仅为居中「记录」，无副标题、无轮播
- [ ] 实验组 Tab 文案为「日历」「记录」；控制组为「记录」「点滴」
- [ ] 切换方案四时 Tab 文案即时变化（demo）；线上按实验分组锁定
- [ ] 暗黑下「记录」标题可读
