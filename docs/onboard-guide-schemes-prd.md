# 点滴 Tab · 新手引导方案一至四 — 产品需求逻辑

> 本文档描述方案一～方案四的**展示逻辑、状态流转与后台可配置项**。配置结构设计参考《【体验】用户能看到更符合记录场景的输入提示》（聚合后台 · 女性健康配置2），采用「开关 + 人群包 + 文案/素材 + 排序 + 兜底」模式。

---

## 1. 适用范围与前置条件

| 项目 | 说明 |
|------|------|
| 页面 | 点滴 Tab（`activeTab = note`） |
| 互斥关系 | 同一用户同一时刻**仅命中一种引导方案**（方案一 / 二 / 三 / 四四选一） |
| 与空值页关系 | 命中任一新手指引方案时，**不展示**记录空值页 / 空白记录页（`blankState`、`emptyState` 强制关闭） |
| 与今日引导关系 | 命中任一新手指引方案时，**不展示**时间轴「今日引导」卡片 |
| 演示场景 | 当前 Demo 默认场景为「场景四 · 记录心情反馈」，时间轴为示例数据；正式环境需按身份/人群下发对应示例时间轴 |

**触发时机（建议，待实验确认）：**

- 用户**首次进入点滴 Tab**，或满足运营配置的「再次展示」条件时，拉取后台引导方案配置；
- 用户已在当前会话内**主动关闭**引导且未命中「再次展示」时，不再自动弹出全屏/蒙层引导（方案三/四可通过右上角入口再次打开，见 §6）。

## 2. 后台配置总结构

**后台位置（建议）：** 业务配置系统 · 女性健康配置2  
**配置项名称（建议）：** 【点滴】新手引导方案配置

### 2.1 方案分流配置（全局）

用于决定用户命中哪一种引导方案。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 开关 | bool | 是 | 开：本条配置生效；关：本条不生效 |
| id | string | 是 | 单条配置唯一标识 |
| 引导方案 | enum | 是 | `方案一` / `方案二` / `方案三` / `方案四` |
| 人群包 key | string | 否 | 聚合后台人群包；未配置则对全部用户生效 |
| 排序序号 | int | 是 | 同一用户命中多条时，取序号最小的一条 |
| 优先级说明 | — | — | 实验分流时，引导方案配置优先于客户端本地默认 |

**下发逻辑：**

1. 用户进入点滴 Tab 时请求配置；
2. 过滤 `开关 = 开` 且命中人群包的记录；
3. 取 `排序序号` 最小的一条，得到 `引导方案` 枚举值；
4. 再加载该方案下的**子配置组**（§2.2～§2.5）。

**兜底：**

- 未下发 / 未命中 / 请求失败 → **不展示新手引导**，点滴页按常规空值/有数据逻辑展示。

### 2.2 方案一子配置组（可配置 · 重点）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 开关 | bool | 是 | 方案一内容是否生效 |
| id | string | 是 | 子配置唯一 ID |
| 人群包 key | string | 否 | 可细分子人群；未配置则继承全局方案分流人群 |
| **前缀文案** | string | 是 | 轮播区固定前缀，默认「在美柚」，≤8 字 |
| **关键词列表** | string[] | 是 | 轮播关键词，每条 ≤8 字，建议 3～6 条；如「记生活点滴」「记体重」「记饮食」 |
| **关键词轮播间隔** | int | 是 | 单位 ms，默认 2000；单条时固定展示不轮播 |
| **引导副标题** | string | 是 | 底部引导区主提示，默认「不知道记什么？从点击按钮开始 👇」，≤24 字 |
| **背景示例时间轴** | 模板 id | 是 | 引用「示例时间轴模板」（见 §7.1），展示在蒙层后方 |
| **蒙层可点击关闭** | bool | 是 | 开：点击渐变蒙层进入完整时间轴；关：仅能通过其他运营入口关闭（一般建议开） |
| **底部输入默认模式** | enum | 是 | 固定 `语音`（方案一隐藏快捷发布 + 号，强调按住说话） |
| 排序序号 | int | 是 | 同方案内多条子配置时的优先级 |

**展示逻辑：**

- 全屏引导展示期间：隐藏底部 Tab Bar；顶栏保留「点滴」标题 + 关闭按钮（方案三/四）。

## 3. 方案一 — 蒙层 + 背景时间轴 + 语音引导

### 3.1 页面结构

```
┌─────────────────────────────┐
│ 顶栏：点滴标题 + 搜索        │
├─────────────────────────────┤
│ 背景：示例时间轴（可滚动区）  │  ← 蒙层下方，视口偏底部
│   · 示例记录卡片 ×N         │
├─────────────────────────────┤
│ 渐变蒙层（可点击）            │
│  ┌ 引导区（居中偏上）────┐   │
│  │ 在美柚                 │   │
│  │ [记体重] ← 关键词轮播   │   │
│  │ 不知道记什么？…👇       │   │
│  └────────────────────────┘   │
├─────────────────────────────┤
│ 底部 Dock：语音模式           │  ← 隐藏 + 号快捷发布
│ [🎤 按住 说话]               │
└─────────────────────────────┘
```

### 3.2 状态流转

| 状态 | 条件 | 表现 |
|------|------|------|
| S0 初始 | 进入点滴 Tab 且命中方案一 | 时间轴滚至**底部**，展示示例记录；蒙层 + 引导区覆盖中下区域 |
| S1 引导中 | `onboardGuideDismissed = false` | 关键词按配置间隔轮播；底部 Dock 默认语音模式 |
| S2 已关闭 | 用户点击蒙层（且 `蒙层可点击关闭 = 开`） | 蒙层与引导区消失，完整时间轴可交互；**不展示**灯泡入口 |
| S3 重置 | 切换引导方案 / 重新进入实验 | 恢复 S0，`onboardGuideDismissed` 重置为 false |

### 3.3 交互细则

1. **关键词轮播**：列表长度 = 1 时不轮播；≥2 时按 `关键词轮播间隔` 循环切换，切换时带入场动画。
2. **蒙层点击**：点击渐变蒙层非 Dock 区域 → 进入 S2；Dock 区域点击不关闭蒙层（避免误触）。
3. **底部 Dock**：`hideQuickFan = true`、`hideQuickFab = true`，不展示右下角 + 号；`defaultInputMode = voice`。
4. **背景时间轴**：使用 `getTimelineOnboardGuide` 模板数据（默认含「健身」「宝宝睡眠」两条示例）；正式环境由 `背景示例时间轴` 模板 id 映射。
5. **头图氛围**：方案一引导预览期间，不展示头部氛围大标题方案。

### 3.4 与输入提示配置的联动（建议）

方案一底部为**语音输入**，「按住说话」文案建议读取【点滴】输入提示文案配置 · `输入类型 = 语音`；若无有效配置，使用硬兜底「按住 说话」。

## 4. 方案二 — 蒙层 + 示例气泡 + 文字输入 + 号引导

### 4.1 页面结构

与方案一相同外层（顶栏 + 背景时间轴 + 蒙层），引导区内容不同：

```
┌ 引导区 ────────────────────┐
│ 不知道记什么？试试这样记👇    │
│  "今天有点腰酸…"  （左气泡） │
│      "早上称了体重…"（右气泡）│
│                    ╲        │
│                     ╲ 曲线箭头 → 指向右下角 +
└────────────────────────────┘
│ 底部 Dock：文字输入模式       │
│ [键盘] [输入框 placeholder]  │
└─────────────────────────────┘
```

### 4.2 状态流转

| 状态 | 条件 | 表现 |
|------|------|------|
| S0 初始 | 命中方案二 | 同方案一，时间轴滚至底部，蒙层展示 |
| S1 引导中 | 未关闭 | 展示主标题 + 示例气泡 + 箭头（若配置开） |
| S1a 箭头隐藏 | 用户点击 + 号 | `是否展示箭头` 且 `箭头在点击+后隐藏` 时，箭头消失 |
| S2 已关闭 | 点击蒙层 | 蒙层消失，完整时间轴；**无**灯泡入口 |

### 4.3 交互细则

1. **底部 Dock**：`defaultInputMode = text`（文字输入），不隐藏 + 号（与方案一差异点）。
2. **经期快捷记录条**：引导期间 `showOnboardGuideScheme2` 时隐藏经期 Dock 快捷条，避免与引导箭头争抢注意力。
3. **示例气泡**：文案来自配置列表；对齐方式按 `气泡对齐方式` 逐条指定。
4. **背景时间轴**：默认使用「方案二预览时间轴」模板（昨天语音+饮食、今天体重等），由 `getBlankScheme2PreviewTimeline` 逻辑等价实现。
5. **曲线箭头**：默认锚定在 + 号按钮左上方；Demo 支持拖拽定位（正式版是否支持运营配置坐标，待评估）。

### 4.4 与输入提示配置的联动（建议）

方案二底部为**文字输入**，placeholder 建议读取【点滴】输入提示文案配置 · `输入类型 = 文本`；兜底「记录生活点滴」。

## 5. 方案三 — 全屏空值动画页

### 5.1 页面结构

全屏浮层 `ep-onboard-fullscreen`，覆盖 Tab Bar。

```
┌─────────────────────────────┐
│ 点滴              [关闭 ×]   │
├─────────────────────────────┤
│ 在美柚，记一切               │
│ 说一句话，情绪·症状·饮食…    │
├─────────────────────────────┤
│ ┌ 演示白卡（循环动画）────┐  │
│ │ 语音条 → 转写打字        │  │
│ │ 标签行（情绪、症状）      │  │
│ │ 迷你 AI 趋势图（可选）    │  │
│ └──────────────────────────┘  │
├─────────────────────────────┤
│      (粉色圆形话筒)          │
│       按住说话               │
└─────────────────────────────┘
```

### 5.2 动画时序（默认）

| 阶段 | 时间（约） | 内容 |
|------|-----------|------|
| T1 | 0～0.25s | 白卡入场 |
| T2 | 0.3～0.5s | 语音条出现 |
| T3 | 0.55～1.25s | 转写文字逐字显示 |
| T4 | 1.75～2.12s | 标签依次出现（情绪、症状） |
| T5 | 2.62～3.07s | 迷你趋势图入场 |
| T6 | 3.07～6.07s | 停留 3s |
| T7 | — | 循环回到 T1 |

### 5.3 状态流转

| 状态 | 条件 | 表现 |
|------|------|------|
| S0 全屏展示 | 进入点滴且命中方案三，`dismissed = false` | 全屏动画循环；Tab Bar 隐藏 |
| S1 关闭动画 | 点击右上角关闭 | 缩小飞入右上角（collapse 动画，约 420ms） |
| S2 收起态 | 关闭完成 | 回到点滴时间轴；若 §2.6 开关开，展示灯泡入口 |
| S3 再次打开 | 点击灯泡 | 回到 S0，`dismissed = false` |

### 5.4 交互细则

1. 底部话筒可按压（Demo 有按下态），**不触发真实录音**（纯演示）。
2. 关闭按钮位于全屏页顶栏右侧，与点滴主顶栏关闭行为一致。
3. 全屏期间不展示底部真实 Dock Publisher。

## 6. 方案四 — 全屏 · 输入演示 + 时间轴卡片一体化白框

### 6.1 页面结构

```
┌─────────────────────────────┐
│ 点滴              [关闭 ×]   │
├─────────────────────────────┤
│     ┌ 固定白框 440px ────┐   │
│     │ 示例               │   │
│     │ [输入条打字演示]    │   │  ← 阶段 A
│     │ ─── 或 ───         │   │
│     │ 时间轴示例卡片      │   │  ← 阶段 B
│     │  09:41 语音+转写    │   │
│     │  体重/心情标签      │   │
│     │  近7日体重趋势+解读  │   │
│     └────────────────────┘   │
├─────────────────────────────┤
│      (粉色圆形话筒)          │
│       按住说话               │  ← 在白框外，固定底部
└─────────────────────────────┘
```

### 6.2 动画时序（默认 9s 循环）

| 时间点 | 事件 |
|--------|------|
| 0.28s 起 | 输入条开始打字 |
| 2.5s | 输入条进入「已发送」态（高亮边框 + 发送动效） |
| 3.1s | 输入条隐藏；白框内展示时间轴卡片 |
| 3.3s 起 | 卡片内转写逐字打字 |
| 4.7s / 5.1s | 依次高亮「体重52公斤」「心情不错」 |
| 5.6s | 展示体重、心情标签 |
| 6.8s | 展示 AI 体重趋势图 + 解读文案 |
| 9.0s | 整轮结束，循环重置 |

### 6.3 状态流转

与方案三相同：全屏 → 关闭收起 → 可选灯泡入口 → 可再次打开。

### 6.4 交互与展示细则

1. **白框**：固定高度，不随内容动态伸缩；内容超出 `overflow: hidden`。
2. **输入演示**：固定在白框内；发送后消失，**不**占用「示例」标题栏下方被裁切区域（时间轴节点负 margin 在方案四内归零）。
3. **AI 卡片**：内联展示趋势图；**不展示**「查看近30天体重变化趋势」入口（`forceInlineAi` 场景下隐藏 Review Entry）。
4. **底部话筒**：仅在白框**外**底部展示，样式同方案三，Demo 为非交互展示。
5. **解读文案**：使用配置项 `AI 解读文案`，默认短句版（见 §2.5）。

## 9. 异常与边界

| 场景 | 处理 |
|------|------|
| 配置拉取中 | 不展示引导，避免闪屏；可展示骨架或保持上一帧 |
| 子配置文案超长 | 客户端截断 + 省略号；后台校验拒绝超长提交 |
| 用户快速切换 Tab | 离开点滴 Tab 不重置 `dismissed`；再次进入是否重播由「再次展示」策略决定（待运营规则） |
| 与语音转写 Demo 冲突 | `voiceTranscribe` 场景下不展示任一新手指引 |
| 方案三/四全屏时 | 隐藏底部 Tab、隐藏真实 Dock；顶栏搜索在方案三/四全屏时仍可见（点滴标题行） |
